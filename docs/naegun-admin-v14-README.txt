내전.GG 운영 콘솔 v14 (기능 구현 1차)

포함
- 좌측 고정 사이드바 (기존 /admin/ 아래 화면 공통 표시)
- 운영 대시보드: RDS 내전/회원/공지/정산 현황, 최근 내전/운영로그
- 회원 검색 및 다중 선택: 랭크 점수/전적/보호 게이지/보호권/GG코인
- 실지급: 랭크 방패 +/-1, 보호권 +/-1, 보호 게이지, 코인 +/- , 승/패 기록 +1 (변경 전 확인, 감사로그, 중복 요청 방지)
- 메인 이벤트 배너: PNG/JPG/WEBP 업로드 3MB 이내, 제목/링크/노출/순서/새 탭, 활성 배너 롤링, RDS 저장
- 메인 공지: RDS Notice 중 published=true 최신 5건 출력, 기존 Discord 포럼 sync는 변경하지 않음
- 기존 관리자 계정 관리 API 유지
- 기존 /admin/scrims/[code]/* 팀/수동 정산/트래커 API와 내전 정보는 그대로 둠

범위/제한
- 관리자 홈페이지/좌측 메뉴 UI 전면 교체. 내전 상세의 기존 내부 폼/기능은 보존되며 개별 상세 UI까지 전면 재설계한 버전은 아님.
- 카드게임/상점 기능은 현재 RDS 모델 목록에 없으므로 임의 테이블을 만들지 않고 이번 버전에 포함하지 않음.
- 보상 변경은 별도 관리자 일괄 보정이며 BO3 경기 결과를 다시 정산하지 않음. DM 전송 기능은 본 버전에 포함하지 않음.
- 배너 이미지는 최대 3MB만 DB의 bytea로 저장해 별도 S3 없이 작동. 고트래픽 환경에서는 이미지 저장소 이전 권장.
- DB는 기존 모델 유지하고 AdminHomeBanner 테이블만 생성. destructive migration 없음.
- 기존 공지 상세 라우트가 확인되지 않아 메인 공지 클릭 시 /notice 게시판으로 이동 (개별 상세 URL은 추가 확인 후 연결).

안전 적용
1. 먼저 백업 생성 및 모델 존재 확인.
2. 새 배너 테이블만 CREATE TABLE IF NOT EXISTS.
3. 새 UI/API 파일 설치. 이전 코드 프로젝트 밖 ~/naegun-project-backups/ 아래 저장.
4. cd ~/naegun-gg && npm run build
5. 성공 시 pm2 restart naegun-gg --update-env && pm2 save
6. 실패 시 PM2 재시작하지 말고 오류 출력 공유.

보안: 관리자 API requireAdmin / Origin 검사, RDS 감사 로그, 작업 키 중복 검사. 실제 운영 서버 인증/빌드/지급 테스트는 미실시.
